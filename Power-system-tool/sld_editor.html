⚡ SLD Editor

Select or place an element to edit its properties.

Workflow:
1. "+ Bus" then click canvas to drop buses.
2. "+ Line" then click bus A, then bus B, to connect.
3. "+ Gen" / "+ Breaker" then click a bus to attach.
4. Click "Select" to click any element and edit its properties (id, kV, R/X, P/Q, ratings...) here.
5. "Export JSON" gives a file matching the PowerSys Network schema (buses/branches/gens/breakers) used by the load-flow, short-circuit, breaker-duty, and arc-flash modules.
